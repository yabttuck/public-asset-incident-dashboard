# Stitch 디자인 수정본

각 `krds_*/code.html` 파일은 브라우저에서 열어 확인할 수 있는 정적 시안입니다. 실제 인증, 검색, 갱신, 처리 데이터 연동은 구현되어 있지 않으며 화면에 표시된 건수와 신고 내용은 예시입니다.

| 폴더 | 페이지 |
|---|---|
| `krds_1` | 로그인 |
| `krds_2` | 운영 대시보드 |
| `krds_3` | 운영 신고 목록 |
| `krds_4` | 신고 상세·처리 패널 |
| `krds_5` | 자산 관리 |
| `krds_6` | 신고자 장애 신고 작성 · 유사 신고 안내 · 접수 완료 상태 |
| `krds_7` | 신고자 내 신고 목록 |
| `krds_8` | 신고자 신고 상세·공개 처리 이력 |
| `krds_9` | 관리자 사용자·운영 기준 관리 |

Tailwind CSS와 아이콘은 CDN을 사용하므로 브라우저에서 스타일을 불러오려면 네트워크 연결이 필요합니다.
