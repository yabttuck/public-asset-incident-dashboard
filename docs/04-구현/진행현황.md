# 단계별 개발 진행 현황

| 단계 | 상태 | 기록 |
|---|---|---|
| 0. 범위·정책 기준선 | 기준선 정리 | P0/P1, 역할, 상태와 보안 원칙을 기존 PRD·SRS·정책서에서 확인. 계정 발급, 기관 SLA, 등급 기준, 보존·배포 정책은 미결정으로 유지. |
| 1. 앱 골격과 개발 환경 | 완료 | Next.js App Router, TypeScript, Tailwind CSS 기반, 공통 토큰·포커스 스타일, 환경 템플릿과 실행 안내를 구성. lint/typecheck 통과, Webpack production build 통과. |
| 2. 인증·프로필·역할 인가 | 코드·DB 스키마 적용 완료, 역할별 런타임 검증 대기 | SSR 로그인·로그아웃·세션 확인, 역할 보호와 프로필 RLS를 구현. 2026-11-26 Supabase 개발 프로젝트에 프로필 마이그레이션 적용. 역할별 테스트 계정은 아직 준비하지 않음. |
| 3. 자산 관리 | 코드·DB 스키마 적용 완료, 역할별 런타임 검증 대기 | 관리자 자산 등록·수정·비활성화 UI와 RLS 정책을 구현. 자산 마이그레이션을 개발 DB에 적용하고 테이블 존재를 확인. |
| 4. 신고 접수·신고자 경험 | 코드·DB 스키마 적용 완료, 역할별 런타임 검증 대기 | 신고 접수·중복 안내·멱등 저장, 본인 목록·상세·공개 업데이트를 구현. 신고 및 이력 테이블과 함수/RLS 마이그레이션을 개발 DB에 적용. |
| 5. 운영 목록·처리·감사 | 코드·DB 스키마 적용 완료, 역할별 런타임 검증 대기 | 검색·필터·페이지 이동, 배정·기한·상태 전이·공개/내부 기록·감사 이력 RPC를 구현. 운영 마이그레이션을 개발 DB에 적용. 동시성·RLS 동작은 역할 계정 준비 후 확인해야 함. |
| 6. SLA·대시보드 | 코드 완료·정책/외부 연동 대기 | 운영 대시보드에 접수·미완료·초과·완료·기한 미지정·담당 미지정 집계와 최근 변경 목록 구현. 미완료의 지정 기한 경과만 초과 처리하고 임박 기준은 정책 미확정으로 집계하지 않음. 실 DB 집계 검증은 미실행. |
| 7. 관리자 사용자·기준 | 조회 화면 완료·승인 정책 대기 | 관리자 전용 사용자/역할/활성 상태 조회와 계정·권한·우선순위·SLA·보존 기준 미결정 현황 화면 구현. 역할 변경·초대·기준값 변경은 승인 정책 미확정으로 미노출. |
| 8. 통합 검증·UAT·배포 준비 | 개발 DB 스키마 확인 완료·런타임 검증 대기 | Supabase SQL Editor에서 4개 마이그레이션을 적용하고 5개 핵심 테이블을 조회해 확인. 적용은 CLI가 아닌 SQL Editor에서 수행했으며 CLI 마이그레이션 이력에는 아직 등록되지 않음. 역할별 테스트 계정, 기관 정책, 기능 케이스 실행, UAT 및 출시 승인은 대기. |

진행 상태는 코드·문서·개발 DB를 확인한 날짜에 갱신한다. 문서 검토만으로 업무 정책 승인을 대체하지 않는다. `.env.local`은 로컬 전용이며 Git에서 제외된다.
