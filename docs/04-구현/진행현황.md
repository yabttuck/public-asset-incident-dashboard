# 단계별 개발 진행 현황

| 단계 | 상태 | 기록 |
|---|---|---|
| 0. 범위·정책 기준선 | 기준선 정리 | P0/P1, 역할, 상태와 보안 원칙을 기존 PRD·SRS·정책서에서 확인. 계정 발급, 기관 SLA, 등급 기준, 보존·배포 정책은 미결정으로 유지. |
| 1. 앱 골격과 개발 환경 | 완료 | Next.js App Router, TypeScript, Tailwind CSS 기반, 공통 토큰·포커스 스타일, 환경 템플릿과 실행 안내를 구성. lint/typecheck 통과, Webpack production build 통과. |
| 2. 인증·프로필·역할 인가 | 코드 완료·외부 연동 대기 | SSR 로그인·로그아웃·세션 확인, 역할 보호, 프로필 RLS 마이그레이션 작성. Supabase 개발 프로젝트와 역할 계정이 없어 DB 적용 및 역할별 런타임 검증은 미실행. |
| 3. 자산 관리 | 코드 완료·외부 연동 대기 | 관리자 자산 등록·수정·비활성화 UI, RLS 및 감사 대상 DB 구조 작성. 실제 Supabase 마이그레이션 적용 검증은 미실행. |
| 4. 신고 접수·신고자 경험 | 코드 완료·외부 연동 대기 | 신고 접수·중복 안내·멱등 저장, 본인 목록·상세·공개 업데이트 구현. RLS/DB 실제 연동 검증은 미실행. |
| 5. 운영 목록·처리·감사 | 코드 완료·외부 연동 대기 | 검색·필터·페이지 이동 목록과 상세 조치 화면, 배정·기한·상태 전이·공개/내부 기록·감사 이력 SQL 트랜잭션 작성. 타입 검사·린트·production build 통과. 실제 DB 적용 및 동시성/RLS 검증은 미실행. |
| 6. SLA·대시보드 | 코드 완료·정책/외부 연동 대기 | 운영 대시보드에 접수·미완료·초과·완료·기한 미지정·담당 미지정 집계와 최근 변경 목록 구현. 미완료의 지정 기한 경과만 초과 처리하고 임박 기준은 정책 미확정으로 집계하지 않음. 실 DB 집계 검증은 미실행. |
| 7. 관리자 사용자·기준 | 조회 화면 완료·승인 정책 대기 | 관리자 전용 사용자/역할/활성 상태 조회와 계정·권한·우선순위·SLA·보존 기준 미결정 현황 화면 구현. 역할 변경·초대·기준값 변경은 승인 정책 미확정으로 미노출. |
| 8. 통합 검증·UAT·배포 준비 | 코드 검증 완료·출시 검증 대기 | typecheck/lint/build 통과. 기능 케이스 실행 0건. 테스트 프레임워크 및 Supabase 개발 환경·테스트 계정·기관 정책·UAT 승인자 부재로 DB/RLS/UX 인수 검증 대기. |

진행 상태는 코드와 기준 문서를 확인한 날짜에 갱신한다. 문서 검토만으로 업무 정책 승인을 대체하지 않는다.
