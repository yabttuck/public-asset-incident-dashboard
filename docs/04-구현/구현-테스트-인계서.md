# 구현·테스트 인계서

상세 설계 범위를 구현하고 QA가 재현 가능한 환경에서 검증할 때 갱신하는 인계 기록이다. 현재 저장소에는 설계 문서만 있으며 애플리케이션 코드, 릴리스, 테스트 환경은 아직 준비되지 않았다. 따라서 본 문서는 QA 인계 완료본이 아니라 구현 준비 상태의 초안이다.

| 항목 | 기록 |
|---|---|
| 프로젝트·릴리스 | 공공 시설물·전산 자산 장애 접수 및 관제 대시보드 / 릴리스 미정 |
| 작성자·QA 인수자 | 작성자 및 QA 인수자 미정 |
| 대상 기준선 | PRD 0.1, SRS 0.1, RTM 0.1, 상세 설계 초안 |
| 테스트 대상 버전 | 없음. 저장소에 앱 코드·빌드 산출물 없음 |
| 인계 일시·상태 | 2026-11-24 KST / 준비 전 |

## 1. 구현 범위 및 상태

아래는 대상 범위와 계획 위치다. 완료 표시는 현재 없으며 구현 시 파일·PR·커밋과 결과로 갱신한다.

| 요구사항 ID | 예정 구현 위치 | 현재 결과 | 설계 변경·후속 |
|---|---|---|---|
| FR-001, FR-002 | src/app 인증 경로, src/lib 권한, Supabase Auth/RLS | 보류: 앱 미생성 | 계정 발급 정책 확정 필요 |
| FR-003 | 자산 기능, Supabase 마이그레이션 | 보류: 미구현 | 자산 유형 기준 확인 |
| FR-004, FR-005 | 신고 작성 및 서버 측 생성 경로 | 보류: 미구현 | 유사 신고는 안내만 제공 |
| FR-006, FR-011 | 신고 목록·대시보드, 서버 쿼리 | 보류: 미구현 | 검색 필드·SLA 임계값 결정 |
| FR-007, FR-008 | 처리 패널·조치 기록 | 보류: 미구현 | 공개/내부 접근 테스트 필요 |
| FR-009, FR-010 | 상태 변경 DB 함수/RPC 및 감사 로그 | 보류: 미구현 | 원자성·동시성 테스트 필수 |
| FR-012 | 첨부·분석·CSV 기능 | 보류: P1 후속 범위 | 파일 정책 승인 전 착수 금지 |
| NFR-001~007 | RLS, 접근성, 반응형, 오류 상태 | 보류: 미검증 | 요구사항별 검증 결과를 RTM에 기록 |

구현 착수 후 각 요구사항의 실제 파일·변경 요청·검증 결과를 [RTM](../01-요구사항분석/요구사항추적매트릭스-RTM.md)에 연결한다. 변경이 생기면 SRS와 설계 문서를 함께 갱신한다.

## 2. 빌드와 테스트 환경

| 항목 | 현재 기록 / 준비 조건 |
|---|---|
| 재현 가능한 빌드·실행 | 앱 스캐폴드와 package.json이 없어 명령 미정. 생성 후 런타임 버전과 lockfile 기준 설치·개발·빌드 명령을 기록 |
| QA 환경·접근 | 환경 주소와 QA 인수자 미정. 공개 저장소에 자격 증명을 기록하지 않음 |
| 환경 설정 | Supabase URL 및 공개 클라이언트 키는 환경 변수로 제공. 서비스 역할 키는 서버 비밀 저장소에만 보관 |
| 데이터·마이그레이션 | Supabase 마이그레이션·테스트 사용자·역할별 fixture 필요. 실행 순서와 초기화 절차는 프로젝트 구성 후 기록 |
| 외부 연동 | Supabase 프로젝트/샌드박스 미준비. 실서비스 개인정보 없이 테스트 데이터 사용 |
| 테스트 문서 | 테스트 계획서와 단계별 검토 체크리스트는 아직 작성되지 않음 |

자격 증명은 지정된 비밀 보관 경로를 통해 공유하고 이 파일이나 Git에 넣지 않는다.

## 3. 구현 확인 결과

| 점검 | 대상 버전·환경 | 결과 | 증빙 |
|---|---|---|---|
| 빌드·코드 검토 | 앱 코드 없음 | 미실행 | 빌드 대상 부재 |
| 단위 테스트 | 테스트 러너 미설정 | 미실행 | 테스트 대상 부재 |
| 주요 흐름 점검 | 인증·접수·처리 UI 미구현 | 미실행 | QA 환경 부재 |

### 남은 이슈 및 인계 영향

| 이슈 | 영향 요구사항·테스트 | 담당·기한 |
|---|---|---|
| 앱 코드와 개발 도구 미생성 | FR/NFR 전체, 빌드 및 테스트 실행 불가 | 구현 담당 미정 |
| 기관별 SLA·계정·분류 정책 미확정 | FR-001/002/007/011, DD-TC-06 | 기관 운영 책임자 미정 |
| QA 환경과 테스트 데이터 부재 | 역할별 RLS 및 핵심 흐름 검증 불가 | QA/운영 담당 미정 |
| 테스트 계획 및 G4 체크리스트 부재 | QA 진입·완료 판단 불가 | QA 인수자 미정 |

## 4. G4 테스트 인계 확인

현재는 구현과 검증이 끝나지 않아 QA 인계 승인을 요청할 수 없다.

- [ ] QA 인수자가 식별 가능한 빌드와 테스트 환경에 접근할 수 있다.
- [ ] 릴리스 요구사항의 구현 위치·변경 결정이 RTM에서 추적된다.
- [ ] 빌드, 단위 테스트, 주요 사용자 흐름의 결과와 제한 사항이 기록됐다.
- [ ] 테스트 계획서와 G4 검토 체크리스트가 작성되고 진입 조건을 충족했다.

| 판단 | 승인자·일시 | 확인 근거·후속 조치 |
|---|---|---|
| 인계 보류 — 구현 및 QA 환경 미준비 | 미정 | 앱 구현, 테스트 계획·환경 구성 후 결과를 갱신하고 재검토 |

인계 승인 전까지 이 파일은 상태 기록용 초안으로 유지한다. 구현이 시작되면 계획 경로를 실제 경로로 바꾸고, 각 검증을 실행한 증빙과 테스트 대상 커밋을 기재한다.
