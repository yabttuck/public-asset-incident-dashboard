# 로컬 개발 환경

## 요구 환경

- Node.js 20.9 이상 (현재 확인된 개발 환경: Node.js 22.13.1)
- npm 10 이상
- Supabase 개발 프로젝트는 인증·데이터 기능을 구현할 때 준비합니다. 현재 앱 골격만 실행하는 데는 필요하지 않습니다.

현재 Next.js 16 기본 Turbopack 빌드는 이 Windows 실행 환경에서 CSS 로더 하위 프로세스 생성 중 종료됩니다. 개발 및 production build 스크립트는 현재 통과한 Webpack 경로를 사용합니다. 환경이 바뀌면 Turbopack 전환을 다시 검토할 수 있습니다.

## 설치와 실행

저장소 루트에서 아래 명령을 실행합니다.

```powershell
npm ci
npm run dev
```

개발 서버가 안내하는 로컬 주소를 브라우저에서 엽니다. 기본 포트는 3000입니다.

## 검토 명령

```powershell
npm run lint
npm run typecheck
npm run build
```

## 환경 변수

`.env.example`을 참고해 로컬 전용 `.env.local`을 만들 수 있습니다. Supabase URL과 publishable key는 인증·데이터 연동 단계에서 개발 프로젝트 값으로 채웁니다. `.env.local`은 Git에 추가하지 않습니다. `service_role` 키는 브라우저나 저장소에 넣지 않습니다.

Auth 프로필 마이그레이션을 로컬에 적용하려면 Supabase CLI 설치 및 개발 프로젝트 연결이 필요합니다. 새 Auth 사용자를 만들면 프로필 트리거가 `reporter` 역할로 기본 생성합니다. 운영 담당자·관리자 계정 승격은 개발 프로젝트 SQL Editor에서 명시적으로 수행하고, 운영 프로젝트에서는 승인된 절차를 따릅니다.

## 화면 시안

`design/stitch/krds_*/code.html`은 별도로 열어 보는 정적 화면입니다. 앱 코드와 데이터 연동을 마친 것으로 간주하지 않습니다.
