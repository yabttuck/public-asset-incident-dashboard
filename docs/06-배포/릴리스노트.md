# 릴리스 노트

## 공공 시설물·전산 자산 장애 접수 및 관제 대시보드 — 릴리스 미정

- **상태:** 아직 배포된 애플리케이션 릴리스 없음
- **대상 커밋 / 빌드:** 없음
- **배포일:** 해당 없음
- **기준 문서:** PRD 0.1 및 waterfall 단계별 설계 초안

### 신규 기능
현재 공개할 구현 기능 없음. 기획·요구사항·시스템/상세 설계·테스트·배포 문서를 준비했다.

### 개선 사항
해당 없음.

### 버그 수정
해당 없음. 애플리케이션 코드와 실행 테스트가 아직 없다.

### 알려진 이슈 및 제한
- 앱 코드, 빌드 산출물, QA 및 운영 환경이 준비되지 않았다.
- 기관 계정 발급, SLA 기준, 우선순위·유형 분류 정책은 미결정이다.
- 실제 데이터와 운영 주소는 설정하지 않았다.

### 호환성 정보
지원 브라우저와 실행 환경은 구현 후 정한다.

### 업그레이드 가이드
현재 릴리스가 없어 업그레이드 절차는 해당 없음. 첫 릴리스에서는 배포 계획서의 마이그레이션 사전 점검과 롤백 절차를 작성·승인한 후 배포한다.
